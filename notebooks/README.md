# Notebooks — la narrativa del proyecto

Estos notebooks cuentan la historia del proyecto en orden. Son la parte que un
reclutador abre para ver cómo piensas, así que priorizan claridad y explicación
sobre densidad de código.

- `01_data_exploration.ipynb` — Carga de precios y factores; comprobaciones de
  sanidad; primera regresión de factores sobre una cartera de referencia.
- `02_audit_analysis.ipynb` — Los tres análisis de la auditoría (atribución,
  fuga de información, reproducibilidad) sobre uno o más agentes.
- `03_report.ipynb` — El informe final: 2-3 gráficos clave + conclusiones en
  prosa clara. Este es el que se exporta a `reports/`.

Convención: cada notebook empieza con una celda de markdown que explica la
pregunta que responde y termina con una conclusión en una frase.
